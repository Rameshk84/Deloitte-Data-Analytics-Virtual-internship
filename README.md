## 📊 Deloitte Data Analytics Virtual Internship (Forage)
🔧 Project: Macaro Industries – Telemetry & Pay Equality Analysis
📁 Project Overview
This project simulates a real-world data analytics task for Deloitte’s virtual internship through Forage. It involves analyzing telemetry data and salary equity data for Daikibo Industries using Tableau.

## 🏭 Part 1: Factory Telemetry Data Analysis
🔍 Objective
Analyze machine telemetry data collected from four Daikibo factories to answer:

Which location had the highest machine downtime?

Which machines were responsible for most breakdowns in that location?

## 🌐 Factory Locations
Meiyo – Tokyo, Japan

Seiko – Osaka, Japan

Berlin – Berlin, Germany

Shenzhen – Shenzhen, China

Each location has 9 machine types, sending telemetry every 10 minutes for May 2021.

🎯 Objective

Utilize algorithm outputs built by the Forensic Tech team
